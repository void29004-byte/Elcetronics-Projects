# Arduino Ultrasonic Radar System 📡

A real-time ultrasonic radar visualization project built using Arduino Uno, an HC-SR04 ultrasonic sensor, a servo motor, and Processing (Java).

The Arduino controls the servo-mounted ultrasonic sensor to scan its surroundings, measures distances to nearby objects, and transmits the readings to a computer. Processing receives this data and displays it through a live radar interface.

This project is part of my self-learning journey in robotics, electronics, and embedded systems, focusing on hands-on experimentation and hardware-software integration.

## 🚀 Features

- Automated scanning from 0° to 180°
- Ultrasonic distance measurement
- Real-time radar visualization
- Live scanning angle and distance display
- Visual markers for detected objects
- Serial communication between Arduino and Processing
- Radar display with semicircular distance rings
- Configurable detection range

## 🛠️ Hardware Components

- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Jumper Wires
- Breadboard (optional)
- USB Cable
- External servo power supply, if required

## 💻 Technologies Used
